# Keep Alive

Keeps free Supabase projects and Render services awake.

**Download:** [KeepAlive.exe](https://github.com/xDhruboVai/Keep-Alive-Releases/releases/latest/download/KeepAlive.exe) → double-click.
It installs itself, starts with Windows, sits in the tray, and updates itself.

Windows may say "Windows protected your PC" the first time (the app isn't code-signed):
**More info** → **Run anyway**.

`links.txt` is the shared list every copy pings. This repo is published automatically;
don't edit it here.
